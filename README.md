# 嵌入式 FPGA 气象灾害预警平台

本工程基于安路 EG4S20 FPGA 与 HX4S20C 开发板，实现一套不依赖外部处理器和软核 CPU 的气象灾害预警与避险多媒体演示系统。

系统从 TF 卡读取 BMP 图像、WAV 音频、字幕及缩略图资源，由 FPGA 硬件逻辑完成 FAT32 文件定位、图像解析、SDRAM 缓存、PCM 音频播放、HDMI 音视频输出和交互控制。

## 主要内容

- 强降雨、高温、台风、雷电和降雪五类天气演练
- FPGA 内部演练数据自动变化及按键人工调节
- 无预警、蓝色、黄色、橙色和红色五级预警状态
- 动态天气效果与等级联动音量
- 风险页面、避险建议页面、男声播报及滚动字幕
- PCM 音频可视化、淡入淡出转场和画面参数调节
- 天气缩略图预载、滑动选择和场景快速进入

## 目录结构

- rtl：Verilog RTL 源码
- constraints：引脚与时序约束
- resources：工程资源
- tf_card：TF 卡运行素材
- vendor：工程依赖文件
- build：已生成位流
- project2_0.al：安路 TD 工程文件
